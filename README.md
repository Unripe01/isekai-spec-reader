# 作品コンセプト

世界では、奇妙な異変が起き始めている。

* 本来存在しない第五の脚を持つ魔物
* 魔法の異常動作
* 死なない魔物
* 突然消える井戸
* 消える鐘
* 存在しなかったことになる建物
* 一部分だけ失われる歌
* 書き換わる古文書
* そして、世界から消える人間

人々はこれらを、

**「魔王復活の兆候」**

だと考えている。

しかし、本当の原因は別にある。

主人公ユウだけが、誰にも見えない「世界の異常」を見ることができる。

ただしユウ自身も、自分の力の正体や、この世界で本当は何が起きているのかを知らない。

---

# 作品の方向性

この作品は、

**「IT知識で異世界無双する話」にはしない。**

システム的な構造はあくまで物語の裏側に存在する。

作中人物たちにとって、

* 魔法は魔法
* スキルは祝福
* 魔物は魔物
* 神は神
* 魔王は魔王

である。

読者にも序盤からすべてを説明しない。

物語の中ではファンタジーとして成立させながら、時折現れる異質な表示によって、

**「この世界、何かおかしくないか？」**

と思わせる。

---

# 世界の裏設定

以下は作者・制作側のみが把握する設定。

**序盤の読者には確定情報として公開しない。**

この世界そのものは、巨大なシステムのような構造を持っている。

長い年月の中で、

* 人間
* 魔物
* 建物
* 魔法
* スキル
* 歴史
* 死者
* 記憶
* 各種記録

などが蓄積され続けてきた。

そして現在、

**世界の保存可能領域が限界に達しつつある。**

代表的な表示：

```text
WARNING
Available Capacity: 0.02%

Cleanup task: failed
Recovery sequence: standby
```

---

# 重要な裏設定

## 魔王

人類から見れば世界を脅かす最大の存在。

魔王の活動が活発化すると魔物などの異常も増えるため、

人々は、

**「すべての異変は魔王復活によるもの」**

だと考えている。

しかし魔王は、本当の意味での根本原因ではない。

裏設定上は、

**世界の容量を非常に大きく消費している存在の一つ。**

つまり、

魔王を倒せば世界が救われる、

という単純な構造ではない。

---

## 世界崩壊の本当の原因

世界が何千年もの間、

**一度も適切に整理されてこなかったこと。**

魔王を倒しても、世界の崩壊は止まらない。

物語後半では、

「敵を倒す」

ことではなく、

**何を残し、何を失うのかを決める**

ことが重要になっていく。

---

# 物語のテーマ

物語後半では、単なる世界崩壊から、

* 記録とは何か
* 記憶とは何か
* 誰にも覚えられていない存在は、本当に存在したと言えるのか
* 世界を救うためなら、何かを消してよいのか
* 誰が「残す価値」を決めるのか

というテーマへ発展していく。

世界を救うために必要なのは、

**最強の攻撃ではなく「残すものを決めること」。**

---

# 主人公

## ユウ

年齢：27歳

元の世界ではSE系の仕事をしていた青年。

特別な勇者気質ではない。

異世界へ突然現れ、この世界について何も知らない状態から物語が始まる。

### 不変のコア

* 合理的
* 面倒事を嫌う
* 無駄なことを嫌う
* 状況を整理して考える
* しかし困っている人間を放っておけない
* 正義感を振りかざすタイプではない
* ヒーローになりたいわけではない

### 判断基準

**なるべく被害を増やさず、必要な問題だけ解決する。**

### 感情表現

危険な状況ほど、比較的冷静になる。

熱血系ではない。

冗談や軽いツッコミはする。

### 絶対にしないこと

自分の都合だけで、関係のない人間を犠牲にすること。

### 物語開始時の考え

**「問題には原因があり、直し方がある」**

### 物語を通して変化する部分

最終的には、

**「直せない問題も存在する」**

ことを知る。

そして、

正解を探すのではなく、

**何を残すかを選択する人間**

へ変化していく。

---

# ユウの能力

ユウには、世界の異常が見える。

ただし、本人は能力の正体を知らない。

ゲームのステータス画面のように何でも見える能力にはしない。

基本的には、

**異常が発生している対象に触れることで、その違和感が感覚的に分かる。**

例：

* 本来存在しない第五の脚
* 壊れた魔法
* 重複した状態
* 不自然につながった構造
* 欠損
* 破損した記録

など。

ユウ自身は、

「ここがおかしい」

「これは余計だ」

「ここが絡まっている」

程度の感覚として認識する。

---

# Recovery Agent

ユウの鑑定結果には通常の「祝福」が表示されない。

一瞬だけ、

```text
AGENT
```

という異質な表示が現れる。

世界の裏側ではユウは、

**Recovery Agent**

として扱われている。

ただし、

**ユウ本人も読者も序盤ではその意味を知らない。**

公式サイト等でも正体を説明しないこと。

伏線としてのみ使用する。

---

# リゼ

巡礼神官。

銀髪。

紫色の瞳。

### 不変のコア

* 冷静
* 生真面目
* 感情だけで判断しない
* 分からないことを分かったふりしない
* 観察力がある
* 信仰心はあるが盲信はしない
* 少し頑固

### 判断基準

**証拠と事実を重視する。**

### 特徴

ユウから、

「別の世界から来た」

と説明されても簡単には信用しない。

代表的な考え方：

**「信じません。ただし、嘘とも判断しません」**

結論が出ないことは、

**「保留します」**

と言える人物。

### 感情表現

基本的には落ち着いている。

不安や恐怖が強くなると、逆に言葉遣いが丁寧になる傾向がある。

### ユウとの関係

序盤から恋愛一辺倒にはしない。

まずは、

**世界の異常を一緒に調査する相棒**

として関係を構築する。

信頼関係が先。

恋愛要素は後から自然に育てる。

ここで世界の「消失」が初めて具体的に描かれる。

* 消える古井戸

# 祝福

この世界では、神々から人に能力が与えられる。

十二歳になると教会で鑑定を受ける。

例：

* 《白光》
* 《剛力》
* 《鑑定》
* 《予知》
* 《転移》

など。

リゼは《白光》の祝福を持つ。

ユウだけは正常に鑑定できない。

---

# 消失

世界の容量不足に伴って発生している重大な異常。

消失は段階的に進む。

初期：

**物理的な存在が消える。**

その後：

**記録が消える。**

さらに：

**人々の記憶から消える。**

最終的には、

**最初から存在しなかったことになる。**

対象は、

* 物
* 建物
* 道
* 言葉
* 歌
* 記録
* 人間

まで拡大する。

---

# 消失記録

第二章でユウが作り始める手書きの記録。

世界から消えたものを、

**忘れないために記録する。**

最初に記録されるもの：

* 古井戸
* 鐘
* 童謡第四番
* 創世記の欠落部分
* ミナ

世界側からは、

```text
manual record detected
externalized memory may resist cleanup
```

と認識される。

つまり、

**人間が世界とは別に手作業で残した記録は、消失に抵抗できる可能性がある。**

この「消失記録」は物語全体の重要アイテムになる。

将来的には、

**世界で最も重要な書物になる。**

そして物語終盤。

その最後のページに、

**ユウ自身の名前を書く日が来る。**

---

# 作中SYSTEM LOG

章末や重要な場面で、ごく短く表示する。

多用しないこと。

例：

```text
Available Capacity: 0.0198%

Recovery Agent: ACTIVE

Manual archive: CREATED

Retention method: UNKNOWN
```

その他：

```text
REGION LOAD FAILED
```

```text
Attempting fallback...
```

```text
Fallback source integrity: 62%
```

```text
Entity deletion detected
```

SYSTEM LOGは読者への説明ではなく、

**意味不明な伏線**

として使用する。

---

# SYSTEM LOGのルール

序盤では絶対に、

「これはサーバーログです」

「この世界はコンピュータです」

などと説明しない。

読者は、

**「なぜファンタジー世界にこんな表示が？」**

という違和感だけを持つ状態にする。

# 執筆ルール

## やらないこと

### IT用語無双にしない

「俺はSEだからメモリリークが分かった！」

のような展開にはしない。

ユウ自身にも世界の正体は分からない。

---

### 説明しすぎない

世界の裏設定をナレーションで説明しない。

現象を先に描く。

読者に考えさせる。

---

### 主人公を万能にしない

ユウは、

**壊れているものなら直せる場合がある。**

しかし、

**すでに失われたものは戻せない。**

「ないものは、直せない」

という制約を守る。

---

### キャラクターの性格を都合で変えない

物語の展開に合わせてキャラクターを動かすのではなく、

**キャラクターの価値観から行動を決める。**

性格のコアは固定する。

変化するのは、物語を通して得た経験や考え方。

---

### リゼを説明係にしすぎない

世界設定を説明するだけのキャラクターにしない。

リゼ自身にも、

信仰、判断、葛藤、目的を持たせる。

---

### すぐ恋愛にしない

ユウとリゼはまず、

**相棒。**

関係性と信頼を積み上げてから恋愛へ発展させる。

---

# 公式サイト

`site/index.html` がプロモーションTOP、`site/episodes/01/` と `site/episodes/02/` が本文ページ。

本文ページは公開用の `site/contents/episodes/episode-XX.md` をブラウザから読み込み、MarkdownをHTMLへ変換して全文表示する。`contents/episodes/` が執筆・管理用の元ファイルで、公開前に同名ファイルを `site/contents/episodes/` へコピーする。
そのため、HTMLファイルを直接開くのではなく、リポジトリ直下でローカルサーバーを起動する。

```text
python -m http.server 4173
```

起動後、`http://localhost:4173/site/` を開く。

## エピソード追加

1. `contents/episodes/episode-03.md` を追加する。
2. `site/contents/episodes/episode-03.md` へ同じMarkdownファイルをコピーする。
3. `site/episodes/03/index.html` を既存話から複製する。
4. ページ内の話数・タイトル・description・`data-source`・前後リンクを更新する。
5. `site/index.html` のEPISODESと最新話導線へカードを追加する。

## 公開

`site/` フォルダの中身だけで公開サイトが完結する。公開先のルートへ `site/` の中身をアップロードする。
