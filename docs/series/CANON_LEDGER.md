# CANON LEDGER

> 本文に一度出た正史を記録する台帳。
> 既存の事実と矛盾する展開を採用する場合は、「以前の認識が誤っていた」と本文内で意味更新できるかを確認する。成立しない場合は採用しない。

## 記録ルール

- 本文で提示された事実だけを `確定` とする。
- 作中人物の証言は、事実と分けて `証言` と記録する。
- 作者側設定は `STORY_BIBLE.md`、現在地は `CURRENT_STATE.md`、未回収の意味は `OPEN_THREADS.md` に置く。
- 正史を訂正するときは既存行を消さず、訂正理由・該当episode・新しい解釈を追記する。

## episode-01：プロローグ／第一章「ないものは、直せない」

### 新しく確定した事実

- 王都アルセリアから北へ十二日の場所にハルカ村がある。
- ハルカ村の人口は、ユウ出現前に百二十三人、ユウを含めると百二十四人。
- ユウはパーカーとジーンズ姿で森に突然現れた。銀貨三枚と、氏名がユウと記された冒険者仮登録証を所持していた。
- ユウは未知の文字を読め、現地の言葉で会話できる。
- 本来四本脚の黒牙狼に、完成した第五の脚が余分に存在した。
- リゼの火球が杖先で膨張し続け、ユウが絡まりをほどくと消えた。
- ユウは異常部分を感覚的に知覚し、余分なものを外し、絡まりをほどける場合がある。
- ハルカ村では街道灯、大岩、北森の小屋、古井戸などが消失している。
- 消失した北森の小屋を覚えていたガイルと、覚えていない住民がいた。
- 角猪には重複、破損、参照不能、missing dataの異常が発生した。
- 半分が欠損した角猪は元となる情報がなく、ユウにも修復できなかった。
- ユウが祈祷所の鑑定板に触れると、祝福は横線となり、ユウにだけ一瞬 `AGENT` が見えた。
- 古井戸は一晩で痕跡ごと消え、ユウとリゼは覚えていたが、村人は存在を認識していなかった。
- 角猪事件の後、村の鐘が音もなく消えた。

- **ユウ**：二十七歳。元の世界ではSE系の仕事。合理的だが、悲鳴を放置できない。
- **リゼ**：巡礼神官。銀髪、紫色の瞳。《白光》の祝福。証拠がないユウの異世界説明を「保留」した。

- **アルセリア**：王都。
- **ルミナ**：記録と知恵の女神。
- **黒牙狼**：本来は四本脚の魔物。
- **角猪**：牛ほどの大きさを持つ魔物。
- **ガイル**：北森の小屋を覚えていた酒場の男として、episode-02でロイドが名前を挙げる。

### 世界ルール／祝福

- 十二歳になると教会で祝福の鑑定を受ける。
- リゼの祝福は《白光》。傷の治療や弱い呪いの祓いに使える。

- 余分なものや残っている異常は直せる場合があるが、欠損して参照元がないものは直せない。

## episode-02：第二章「消えた鐘」

### 新しく確定した事実

- ハルカ村の鐘は、縄の切断跡もなく消失した。
- 鐘番の老人は鐘を十五年鳴らしていたが、形・色・大きさを思い出せなくなった。
- ユウは鐘に `reference missing`、`object unavailable`、`restore source: none` を認識し、戻せなかった。
- 消失は物理的存在だけでなく、その形の記憶、公的記録、地図、歌へ進む。
- ハルカ村の童謡は五番まであるが、四番だけがリゼの記憶と子供たちの認識から欠落した。
- 古い創世記の破損箇所から「すべての命、名、出来事を、失われず忘れられないよう世界の外側に記録した」という内容が一時復元された。
- 復元した文章と本の意味は急速に記憶から薄れた。リゼが紙へ断片を書き残した。
- 夜空に白い亀裂が生じ、ユウに `REGION LOAD FAILED`、`Attempting fallback...`、`Fallback source integrity: 62%` が見えた。空は元へ戻った。
- 少女ミナが、部屋、記録、周囲の記憶ごと消失した。直後は母親だけが娘を覚えていた。
- ユウは手書きで消えたものを残す《消失記録》を作り始めた。
- 手書き記録に対して `manual record detected`、`externalized memory may resist cleanup` が表示された。

### キャラクター／固有名詞

- **ロイド**：ハルカ村の村長。五十代後半、長い髭。考えるとき右眉を触る。
- **ミナ**：十四歳、茶色い髪。ハルカ村の少女。存在ごと消失した。
- **リーベル**：北街道沿いの町。王都へ向かう伝令が馬を替える地点。
- **セド**：名前はepisode-03で確定するが、五日前にリーベル方面へ出され未帰還の使者がいることはこの話で提示済み。

### 世界ルール／認識の更新

- 消失は「物 → 記録 → 記憶 → 最初から存在しなかった状態」へ進む可能性がある。
- 消失から記憶消去までに時間差または個人差がある可能性は示されたが、条件は未確定。
- 人間が世界内部の既存記録とは別に手作業で残した記録は、消失に抵抗する可能性がある。
- 一般住民は空の異常を魔王復活として解釈した。ユウは別の異常だと感じたが、真相は知らない。

### 消失記録の初期内容

- 古井戸。
- 鐘。
- 童謡第四番。
- 創世記の欠落部分。
- ミナ。

## episode-03：第三章「道が一本多い」

### 新しく確定した事実

- 翌朝、ユウもミナの顔や名前を自然には思い出せず、消失記録から事実を再構成した。
- リゼはミナを完全に忘れていたが、自分の記憶と矛盾する手書き記録を証拠として採用した。
- ミナの母親は「夫と二人暮らし」と認識していた。家の軒先には、持ち主を知らない子供用の靴が片方残った。
- ユウとリゼは、ロイドから馬、旅支度、リーベル衛兵隊宛書状を受け取り、ハルカ村を出た。
- 北街道で九里の道標の次が七里となり、八里の道標を確認できなかった。道標だけか道そのものかは不明。
- 石橋北側で、日没前に一本だった街道が夜に二本へ増えた。
- 増えた左の道に入らず、二本の木へ縄を張り、石三個を置いた。
- 増えた道からハルカ村の使者セドが現れた。本人の認識では十三日の朝に出発し三、四時間歩いたが、実際は十八日で五日経過していた。
- セドの所持する封書は十三日付で、村長印があり、封は切られていない。
- 夜明けには増えた道が消え、元の樫が戻った。縄は一本の樫へ巻き付き、石三個は根元に並んだ状態で残った。
- リーベルの門番は、セドが三日前に同じ門を通り、村長印付き書状を持っていたと証言した。
- リーベルの衛兵は、セドがつい先ほどまで詰所にいたと証言した。
- 現時点で、同一人物セドが二人存在する可能性がある。二人はまだ本文内で対面していない。

### キャラクター／固有名詞

- **セド**：ハルカ村からリーベルへ送られた三十代ほどの使者。泥だらけの旅装で増えた道から帰還した。
- **北街道の石橋**：日没前に街道一本を確認し、夜間分岐が発生した場所。
- **リーベルの門番**：セドを三日前に通したと証言。
- **リーベルの衛兵**：セドがつい先ほどまで詰所にいたと証言。

### 世界ルール／認識の更新

- 消失記録を読むことで、失った記憶そのものではなく、存在した事実を再構成できる。
- fallback系異常では、夜に別の地形が成立し、朝に元の地形が復帰しうる。
- fallback中に置いた物は、元の地形へ対応する別状態で残る場合がある。
- fallbackは人の経過時間や同一性にも関係し、同じ存在を二つ成立させる可能性がある。
- この意味更新を、新しい時間移動・並行世界・分身魔法という独立設定へ分離しない。

### 後から無言で変更してはいけない事項

- 八里について、消えたのが道標か一里分の道かは未確定。
- 門前のセドは五日前の日付を持つが、本人には数時間の認識しかない。
- 町内のセドは証言上の存在であり、episode-03終了時点では直接確認していない。
- 二人のセドはfallback系伏線の意味更新として扱う。

## episode-04：第四章「同じ名前を二度書く」

### 新しく確定した事実

- ユウ、リゼ、北街道から来たセドはリーベル衛兵詰所で、町内にいたセドと同時に対面した。
- 二人のセドは顔立ち、体格、右手首の古い傷、ハルカ村を出た十三日朝までの記憶、携行品の袋のほつれが一致する。
- 二人は同じロイドの書状を一通ずつ持っていた。二通は内容、筆跡、改行、墨のにじみ、折り目まで一致し、別々に書かれたとは考えにくい。
- リーベルの台帳には、十五日にセドが北門から入り、以後十八日まで在町していた記録がある。
- 詰所にいたセドは、十三日夕方以降も北街道を進み、十四日夜に森を越えた先の小屋で泊まり、十五日午後にリーベルへ着いたと証言した。
- 北街道から来たセドは、十三日朝から数時間歩いた認識のまま、増えた道からユウたちの野営へ出た。
- 二人のセドの食料の残量と、十三日以後の記憶・衣服の状態は異なる。二人は同じ出発時点から、別の経過を持つ。
- 二人は消失記録にそれぞれ「セド」と署名した。筆跡は似ているが、上の署名は落ち着き、下の署名は最後の払いが強く紙に食い込んでいる。
- ユウは消失記録に「十八日。リーベル詰所にて、同一人物と考えられるセド二名を同時に確認。現時点で、どちらかを偽物と判断する根拠なし。」と記した。
- リーベルの衛兵隊長は、ひとまず二人のセドを町から出さないと判断した。滞在方法・監視方法は未確定である。
- 町内のセドは、十四日に北街道八里の道標を見たと証言した。右側、腰ほどの石、上部の欠け、荷紐を締め直したという具体的な記憶を持つ。
- ユウとリゼは十八日に同区間と思われる場所で八里の道標を確認できなかった。二つの観測は一致していない。
- リーベルの鐘は夕方に三度、通常どおり鳴った。町の人々はそれを異常と認識していない。

### キャラクター／固有名詞

- **リーベル衛兵隊長**：四十代ほど。村長印付き書状と北門台帳を管理し、二人のセドを町内に留める判断をした。氏名は未確定。
- **詰所のセド**：十五日にリーベルへ到着した記録を持つセド。以後の三日間を町で過ごしている。
- **北街道のセド**：増えた道から現れ、本人には十三日から数時間しか経過していないセド。

### 世界ルール／認識の更新

- fallback系の異常は、同じ出発時点・同じ書状を持つ人物を、異なる経過と状態のまま同時に成立させうる。
- 二人のセドは同時に確認されたが、どちらかが偽物である根拠、優先される存在、共存できる期間は未確定である。
- 公的な台帳と封書は異常を即座に解消せず、矛盾を記録として残す。
- 八里の道標は、十八日に確認できなかった事実と、十四日に見たというセドの証言が並存している。道標自体が消えたのか、道の状態が異なったのかは未確定である。

### 後から無言で変更してはいけない事項

- 二人のセドは第四章で直接対面し、双方が同時に存在することをユウとリゼが確認した。
- 二通の書状は極めて高い一致を示し、二人は別々に書かれた書状を携行しているわけではない。
- 二人のセドを偽物、分身、時間移動、並行世界と断定してはいない。
- 八里を見たのは詰所のセドの証言であり、ユウとリゼによる十八日の直接確認ではない。

## episode-05：第五章「昨日は一つだった」

### 新しく確定した事実

- 調査上の区別として、増えた北街道の分岐から現れたセドを「北街道のセド」、十五日にリーベルへ到着したセドを「十五日のセド」と呼ぶことになった。いずれも本人の固有名ではなく、事実を先取りしないための便宜的な呼称である。
- 衛兵隊長は、少なくとも十八日夜は二人を町から出さず、同じ宿の別室に置くと決めた。十五日のセドは六号室、北街道のセドは七号室で、北街道のセドには衛兵一人が付いた。
- 宿主人は十五日のセドが三日前から六号室に泊まり、毎晩夕食を出していたことを覚えている。北街道のセドは十八日に七号室へ宿泊した。
- 十八日、宿帳には北街道のセドの「セド　ハルカ村　七号室」と、同名同容姿の男二名を同時に確認した旨、宿主人の署名が記された。
- 十五日のセドはリーベル到着後、宿で毎晩酒を飲んでいた。北街道のセドは酒を好まず、父が酒で身体を壊したことを理由に挙げた。十三日までの二人はともに酒嫌いだったと答えたが、十五日のセドは飲み始めた理由を説明できなかった。
- ユウは、二人がハルカ村へ戻ること、あるいは片方だけを戻すことを現時点では避けるべきだと考えた。どちらかを選ぶ根拠がないためである。
- 十九日朝、ユウとリゼは六号室と七号室で二人のセドの存在を直接確認した。消失記録にある二人の署名、区別、宿主人の署名も残っていた。
- 同じ朝、宿帳から十八日に追加された北街道のセドの宿泊記録、二名同時確認の記載、宿主人の署名が消失していた。削った跡や墨を消した跡はなかった。
- 宿主人は十五日のセドだけを覚え、北街道のセドと十八日の二名同時確認を覚えていなかった。ただし、消失記録に残った自分の署名は自分の筆跡と認めたが、書いた記憶はなかった。
- 七号室には使用済みの寝具と北街道のセドの荷物が残っていた。宿主人は部屋、荷物、本人を見ても、誰を七号室へ泊めたのか思い出せなかった。
- 衛兵詰所には十八日の「同一人物と考えられる男二名を確認。町外への移動を一時制限。」という記録と担当衛兵の署名が残り、担当衛兵も二人を覚えていた。
- ユウが宿帳と消失記録に触れても、赤い線、灰色の欠損、異質な文字などの異常は知覚できなかった。
- 北街道のセド本人が存在する間に、一部の記録と記憶からのみその存在が欠落した。消失の進行順序が固定とは限らない可能性が、観測事項として記された。

### キャラクター／固有名詞

- **北街道のセド**：増えた北街道の分岐から現れたセドに対する、調査上の便宜的な呼称。
- **十五日のセド**：十五日にリーベル北門へ到着した記録を持つセドに対する、調査上の便宜的な呼称。
- **宿主人**：リーベルの宿を営む人物。十五日のセドの滞在を覚えていたが、十九日朝には北街道のセドと十八日の二名同時確認を忘れていた。氏名は未確定。

### 世界ルール／認識の更新

- 同じ出来事を同じ日に人が手で残しても、消失記録、宿帳、衛兵詰所の記録で残存の有無が異なりうる。また、宿帳と宿主人の記憶が欠落しても、使用済みの寝具や本人の荷物といった物証は残りうる。どの条件が差を生んだかは未確定である。
- 人物が消えていない段階でも、その人物に関する一部の記録と、一部の人間の記憶だけが先に欠落しうる。
- この出来事を「北街道のセドが偽物だから消される」「後から増えた方が必ず消える」という法則に確定してはいけない。

### 後から無言で変更してはいけない事項

- 北街道のセドと十五日のセドは、第五章時点でも二人とも存在している。
- 十八日の宿帳の北街道のセドに関する追記と宿主人の記憶は、十九日朝に欠落したが、七号室の生活痕と荷物、消失記録、衛兵詰所の記録・担当衛兵の記憶は残った。
- 北街道のセドと十五日のセドという呼称は真贋や優先順位を示さない、調査上の区別である。
- 消失の進行順序は固定でない可能性が示されたにとどまり、原因・条件・法則は未確定である。

## episode-06：第六章「どちらの昨日か」

- 救援隊は地図、灰色の道標、丘、二本松、沢が一致する現地を直接確認した。塔、瓦礫、焼け跡、炉の灰はなく、建っていた場所には長く育ったような草と太い根があった。ユウにも修正できる異常は見えなかった。
- 南斜面の土中から応答音があり、ベルトの構造図を丘へ重ねて掘る位置を推定した。ガレスは上から土を落とす危険を避け、空気を通すため南斜面を横から掘るよう命じた。
- 土中には地下室の石壁が残っていた。救援隊はハンナと、頭を負傷したユルドを生きて救出した。リゼは《白光》をユルドの呼吸を安定させ、運び出せる状態にするためだけに使った。
- ハンナとユルドは合図用の油を運ぶため地下へ下り、ダリオとロアは屋上にいた。階段側の明かりが消えた後、地下室の扉がなくなり、その場所が土になっていた。崩落音は聞いていない。
- ダリオとロアは現地で見つからず、逃走の足跡も確認されていない。二人の生死と所在は未確定である。
- ハンナとダリオは、塔が消える直前、北の稜線に「黒地に、白い角を二本交差させた」旗を三本確認した。ハンナは王都の教本で見た魔王軍旗と同じだと証言した。
- 黒牙狼の群れは旗の手前から南へ逃げていた。救援隊が到着した時点では、北の稜線に旗も人影も見えなかった。
- ガレスは負傷者を抱えた人数で北進すれば救援対象を増やすと判断し、いったん最寄りの見張り台へ戻る。ベルトの報告と生存者を王都へ送り、兵と治療役を増やして戻る意思を示した。
- ベルトの構造図には、地下室から二人を救出した位置と、ダリオとロアを確認できなかった事実が追記された。ハンナは、対応する扉が消えた地下室の鍵を首から下げたままである。

### 世界ルール／認識の更新

- 建物の上部と出入口が跡形なく失われても、地下の一部と中にいた人が残る場合がある。何が残るかの条件や、従来の消失・fallbackとの関係はまだ分からない。
- 完全ではない構造図でも、現地の目印、地下からの応答、失敗時の危険を合わせれば救助の判断に使える。記録は原因を説明するだけでなく、まだいる人へ届くためにも機能する。
- 魔王軍旗、狼の南下、煙の消失、塔の消失が近い場所と時間で観測され、魔王を無関係とすることも難しくなった。ただし、これは因果の確定ではなく、魔王軍を追う理由が生じた段階である。
