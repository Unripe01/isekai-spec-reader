# CANON LEDGER

> 本文に一度出た正史を記録する台帳。
> 既存の事実と矛盾する展開を採用する場合は、「以前の認識が誤っていた」と本文内で意味更新できるかを確認する。成立しない場合は採用しない。

## 記録ルール

- 本文で提示された事実だけを `確定` とする。
- 作中人物の証言は、事実と分けて `証言` と記録する。
- 作者側設定は `STORY_BIBLE.md`、現在地は `CURRENT_STATE.md`、未回収の意味は `OPEN_THREADS.md` に置く。
- 正史を訂正するときは既存行を消さず、訂正理由・該当episode・新しい解釈を追記する。

## episode-01：プロローグ／第一章「ないものは、直せない」

### 新しく確定した事実

- 王都アルセリアから北へ十二日の場所にハルカ村がある。
- ハルカ村の人口は、ユウ出現前に百二十三人、ユウを含めると百二十四人。
- ユウはパーカーとジーンズ姿で森に突然現れた。銀貨三枚と、氏名がユウと記された冒険者仮登録証を所持していた。
- ユウは未知の文字を読め、現地の言葉で会話できる。
- 本来四本脚の黒牙狼に、完成した第五の脚が余分に存在した。
- リゼの火球が杖先で膨張し続け、ユウが絡まりをほどくと消えた。
- ユウは異常部分を感覚的に知覚し、余分なものを外し、絡まりをほどける場合がある。
- ハルカ村では街道灯、大岩、北森の小屋、古井戸などが消失している。
- 消失した北森の小屋を覚えていたガイルと、覚えていない住民がいた。
- 角猪には重複、破損、参照不能、missing dataの異常が発生した。
- 半分が欠損した角猪は元となる情報がなく、ユウにも修復できなかった。
- ユウが祈祷所の鑑定板に触れると、祝福は横線となり、ユウにだけ一瞬 `AGENT` が見えた。
- 古井戸は一晩で痕跡ごと消え、ユウとリゼは覚えていたが、村人は存在を認識していなかった。
- 角猪事件の後、村の鐘が音もなく消えた。

### キャラクター／固有名詞

- **ユウ**：二十七歳。元の世界ではSE系の仕事。合理的だが、悲鳴を放置できない。
- **リゼ**：巡礼神官。銀髪、紫色の瞳。《白光》の祝福。証拠がないユウの異世界説明を「保留」した。
- **ハルカ村**：宿屋、鍛冶屋、酒場、祈祷所、広場、風車などがある小村。
- **アルセリア**：王都。
- **ルミナ**：記録と知恵の女神。
- **黒牙狼**：本来は四本脚の魔物。
- **角猪**：牛ほどの大きさを持つ魔物。
- **ガイル**：北森の小屋を覚えていた酒場の男として、episode-02でロイドが名前を挙げる。

### 世界ルール／祝福

- 十二歳になると教会で祝福の鑑定を受ける。
- リゼの祝福は《白光》。傷の治療や弱い呪いの祓いに使える。
- 《剛力》《鑑定》《予知》《転移》などの祝福が存在する。
- ユウの能力は正常な祝福として鑑定できない。
- 余分なものや残っている異常は直せる場合があるが、欠損して参照元がないものは直せない。

## episode-02：第二章「消えた鐘」

### 新しく確定した事実

- ハルカ村の鐘は、縄の切断跡もなく消失した。
- 鐘番の老人は鐘を十五年鳴らしていたが、形・色・大きさを思い出せなくなった。
- ユウは鐘に `reference missing`、`object unavailable`、`restore source: none` を認識し、戻せなかった。
- 消失は物理的存在だけでなく、その形の記憶、公的記録、地図、歌へ進む。
- ハルカ村の童謡は五番まであるが、四番だけがリゼの記憶と子供たちの認識から欠落した。
- 古い創世記の破損箇所から「すべての命、名、出来事を、失われず忘れられないよう世界の外側に記録した」という内容が一時復元された。
- 復元した文章と本の意味は急速に記憶から薄れた。リゼが紙へ断片を書き残した。
- 夜空に白い亀裂が生じ、ユウに `REGION LOAD FAILED`、`Attempting fallback...`、`Fallback source integrity: 62%` が見えた。空は元へ戻った。
- 少女ミナが、部屋、記録、周囲の記憶ごと消失した。直後は母親だけが娘を覚えていた。
- ユウは手書きで消えたものを残す《消失記録》を作り始めた。
- 手書き記録に対して `manual record detected`、`externalized memory may resist cleanup` が表示された。

### キャラクター／固有名詞

- **ロイド**：ハルカ村の村長。五十代後半、長い髭。考えるとき右眉を触る。
- **ミナ**：十四歳、茶色い髪。ハルカ村の少女。存在ごと消失した。
- **リーベル**：北街道沿いの町。王都へ向かう伝令が馬を替える地点。
- **セド**：名前はepisode-03で確定するが、五日前にリーベル方面へ出され未帰還の使者がいることはこの話で提示済み。

### 世界ルール／認識の更新

- 消失は「物 → 記録 → 記憶 → 最初から存在しなかった状態」へ進む可能性がある。
- 消失から記憶消去までに時間差または個人差がある可能性は示されたが、条件は未確定。
- 人間が世界内部の既存記録とは別に手作業で残した記録は、消失に抵抗する可能性がある。
- 一般住民は空の異常を魔王復活として解釈した。ユウは別の異常だと感じたが、真相は知らない。

### 消失記録の初期内容

- 古井戸。
- 鐘。
- 童謡第四番。
- 創世記の欠落部分。
- ミナ。

## episode-03：第三章「道が一本多い」

### 新しく確定した事実

- 翌朝、ユウもミナの顔や名前を自然には思い出せず、消失記録から事実を再構成した。
- リゼはミナを完全に忘れていたが、自分の記憶と矛盾する手書き記録を証拠として採用した。
- ミナの母親は「夫と二人暮らし」と認識していた。家の軒先には、持ち主を知らない子供用の靴が片方残った。
- ユウとリゼは、ロイドから馬、旅支度、リーベル衛兵隊宛書状を受け取り、ハルカ村を出た。
- 北街道で九里の道標の次が七里となり、八里の道標を確認できなかった。道標だけか道そのものかは不明。
- 石橋北側で、日没前に一本だった街道が夜に二本へ増えた。
- 増えた左の道に入らず、二本の木へ縄を張り、石三個を置いた。
- 増えた道からハルカ村の使者セドが現れた。本人の認識では十三日の朝に出発し三、四時間歩いたが、実際は十八日で五日経過していた。
- セドの所持する封書は十三日付で、村長印があり、封は切られていない。
- 夜明けには増えた道が消え、元の樫が戻った。縄は一本の樫へ巻き付き、石三個は根元に並んだ状態で残った。
- リーベルの門番は、セドが三日前に同じ門を通り、村長印付き書状を持っていたと証言した。
- リーベルの衛兵は、セドがつい先ほどまで詰所にいたと証言した。
- 現時点で、同一人物セドが二人存在する可能性がある。二人はまだ本文内で対面していない。

### キャラクター／固有名詞

- **セド**：ハルカ村からリーベルへ送られた三十代ほどの使者。泥だらけの旅装で増えた道から帰還した。
- **北街道の石橋**：日没前に街道一本を確認し、夜間分岐が発生した場所。
- **リーベルの門番**：セドを三日前に通したと証言。
- **リーベルの衛兵**：セドがつい先ほどまで詰所にいたと証言。

### 世界ルール／認識の更新

- 消失記録を読むことで、失った記憶そのものではなく、存在した事実を再構成できる。
- fallback系異常では、夜に別の地形が成立し、朝に元の地形が復帰しうる。
- fallback中に置いた物は、元の地形へ対応する別状態で残る場合がある。
- fallbackは人の経過時間や同一性にも関係し、同じ存在を二つ成立させる可能性がある。
- この意味更新を、新しい時間移動・並行世界・分身魔法という独立設定へ分離しない。
