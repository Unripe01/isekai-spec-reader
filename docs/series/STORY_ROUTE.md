# STORY ROUTE

> 物語の背骨を「話数」ではなく「到達条件」で管理する。
> 各Phaseの具体的な事件、犯人、章末展開は固定せず、執筆時の即興余地として残す。

## 運用原則

- Phaseの長さと話数は固定しない。
- 話数より、各Phaseの到達条件と物語上の必要性を優先する。
- 新しい事件を作る前に、既出の異常や伏線の意味を別の場所・別の立場から更新できないか検討する。
- Phase終了条件を満たす前に次Phaseの核心を説明しない。
- 出口条件を満たしても、自動的に次Phaseへ移る必要はない。人物の感情と移動に自然な接続を置く。
- 展開を引き延ばすためだけの事件、町、魔物、世界異常を追加しない。

## 想定連載規模

- 想定規模は**全30〜50話程度**。
- 中心値は**35〜45話程度**で完結する長編。
- 「全40話」のような固定話数や、各Phaseの終了episodeは設定しない。
- 各Phaseに記載する話数レンジは進行確認の参考値であり、締切やノルマではない。
- Phaseの到達条件を早く満たした場合は、参考話数より短くても次へ進む。
- 人物関係、既存伏線の回収、重要事件、SSRを自然に描くため必要なら、参考話数を数話超えてよい。
- 100話以上続けること自体を目標にしない。必要なところまで書き、世界の謎、人物の変化、消失記録を収束させて終える。
- 消失記録の最後のページにユウ自身の名前を書く展開を、初期伏線が読者から薄れるほど先送りしない。ただし、その場の状況や最終選択の内容は現時点で固定しない。

### 話数を増減してよい理由

- キャラクター関係を自然に積み上げる。
- 既存伏線を丁寧に回収する。
- AI即興によるSSRが本筋を深める。
- 一つの重要事件を無理に一話へ圧縮すると不自然になる。

### 話数を増やしてはいけない理由

- 想定話数へ届かせる。
- 新しい魔物や新しい異常を毎話出す。
- 本筋と関係のない町を追加する。
- 「今週の世界バグ」のような事件消化型連載を続ける。
- 既存伏線を進めず、新しい謎だけを追加する。
- この作品を連載し続けること自体を目的にする。

## 長期化防止と意味更新

本作の強みは、新しい怪異の数ではなく、**すでに読者が知っている異常の意味が一段ずつ更新されること**にある。

| 既出要素 | 更新された意味 |
| --- | --- |
| 五本脚の魔物 | 世界に不具合がある。 |
| 消える井戸 | 物体そのものが失われる。 |
| 消えた鐘 | 記録や記憶まで失われる。 |
| ミナ | 人間も存在ごと失われる。 |
| 消失記録 | 外部に残した記録は抵抗できる可能性がある。 |
| fallback | 消えるだけでなく、古い／別の状態が同時に成立する可能性がある。 |
| セド | entityそのものの整合性が破綻し、同一人物が二人存在する可能性がある。 |

新しい現象を考えたときは、この列の続きとして既存要素の意味を更新できるかを先に検討する。同じ種類の事件を繰り返すだけなら、事件を増やさずPhaseを進める。

## 各Phaseの終了判定

「参考話数まで書いた」ことは終了条件にならない。次の条件で判断する。

- そのPhaseで読者に理解させるべきことを描けた。
- 主要キャラクターが次へ進む理由を持った。
- 主要な持ち越し伏線が次Phaseへ自然につながった。
- 同じ種類の事件を繰り返し始めていない。

条件を満たしたら参考話数より短くても次Phaseへ進む。重要な展開が自然に伸びた場合は数話超えてよいが、出口条件を満たした後に同種事件を追加して滞在し続けない。

## SSRによる話数変更

SSRが生まれても、面白さだけで予定ルートを変更しない。追加話数を認める前に、次を確認する。

1. 現在Phaseの目的を深めるか。
2. 既存伏線へ接続できるか。
3. 将来の回収先があるか。
4. 全体を十話以上引き延ばす新規大設定ではないか。

四条件を満たすSSRには必要な話数を追加してよい。episode-03のセド重複のように、既存のfallbackを本筋へ深く接続する展開を歓迎する。

## 戦闘・アクションの長期配置

戦闘回の数や配置は固定しない。各Phaseの目的を進めるために必要な場合に使う。

一方で、調査・記録・会話だけが長期間続き、表側のダークファンタジーとして存在している魔物、魔法、魔王、人間側の戦力が物語から事実上消えていないかは継続的に確認する。

戦闘を追加するためだけに、新しい魔物、新しい能力、新しい世界異常を作らない。既出の魔物、魔法、消失、破損、fallback、記録の食い違いなどを、戦闘という別の状況から意味更新できないかを優先する。

| Phase | 戦闘・アクションの役割 |
| --- | --- |
| Phase I：異常を知る | 魔物との直接的な危機を通して、ユウの能力と世界異常を読者に体感させる。episode-01までに確立した「戦闘中にも世界がおかしくなる」という入口を担う。 |
| Phase II：村の外へ | 小〜中規模の戦闘や危機を通して、異常が魔物だけではなく、魔法、人の認識、戦闘後の記録や証言にも及びうることを描ける。セドやfallbackなど既出要素の意味更新を優先する。 |
| Phase III：人間の記録と世界の記録 | 騎士、教会、公的組織など複数人が関わる戦闘を扱える。戦闘そのものだけでなく、死者数、負傷者、命令、報告書、功績など「戦った後に残る記録」と世界の記録の矛盾を描く機会にする。 |
| Phase IV：魔王という答え | 長編中もっとも王道ファンタジーとしての戦闘を前面に出してよいPhase。魔王軍との衝突や大規模戦闘を通して、「魔王を倒せば世界が救われる」という登場人物と読者の仮説に十分な説得力を持たせる。 |
| Phase V：何を残すか | 戦闘を最終解決そのものにはしない。戦うことでは救えない状況や、戦闘の勝敗とは別に何を残すかを選ばなければならない状況へ収束させる。必要な戦闘は残してよいが、最終問題を「最後の敵を倒すこと」へ置き換えない。 |

## Phase I：異常を知る

**範囲**：ハルカ村と北街道入口周辺  
**参考話数**：episode-01〜03前後  
**状態**：完了（episode-01〜03）

### 開始時に読者が知っていること

- 王道ファンタジーに見える世界で、容量不足を示す異質な警告が出ている。
- ユウは元の世界から突然現れ、この世界の常識を知らない。

### このPhaseで意味が更新される既存設定

- 魔物の奇形は単なる変異ではなく、重複・破損・missing dataを含む。
- 「壊れる」は「消える」へ進み、消失は記録・記憶・人間の存在まで及ぶ。
- `fallback` は単なる復旧表示ではなく、不完全な代替状態や重複した存在を成立させうる。
- 手書きの外部記録は、消失した事実の再構成に使える可能性がある。

### Phase終了時に判明してよいこと

- ユウは異常部分を知覚し、直せる場合があるが、欠損したものは戻せない。
- 異常はハルカ村の物だけではなく、記録、記憶、人、道と時間感覚に及ぶ。
- 同じ人物が二人存在している可能性がある。
- 一般社会はこれを魔王復活の兆候として理解する。

### まだ明かしてはいけないこと

- 世界のシステム的構造の全容。
- Recovery Agentの由来と最終目的。
- fallbackの完全な機構。
- 魔王が根本原因ではないという作者側の結論。
- 最終的に何を残すか、誰を残すか。

### 次Phaseへの出口条件

- ユウとリゼがハルカ村を出る。
- リーベルへ到達する。
- ハルカ村だけでは説明できない異常の証拠として、二人のセド問題が発生する。

## Phase II：村の外へ

**範囲**：リーベルと周辺地域  
**参考話数**：episode-04〜10前後  
**状態**：episode-09で出口条件を満たし完了。異常がハルカ村だけの局所現象ではなく、公的記録にも及ぶ証拠がそろい、ユウとリゼは王都の衛兵隊・ルミナ神殿へ向かう。

### 開始時に読者が知っていること

- ハルカ村では、物・記録・記憶・人の消失とfallback系異常が起きた。
- ユウとリゼは消失記録を持ち、手書き記録を証拠として扱い始めている。
- リーベルには、三日前に到着したセドと、今到着したセドが同時に存在する可能性がある。

### このPhaseで意味を更新する既存設定

- ハルカ村で起きた異常が、別の土地や社会制度ではどう見えるか。
- 魔王復活という社会的解釈が、証拠・信仰・行政・噂にどう影響するか。
- fallbackが「場所の復帰」だけでなく、人の同一性や公的記録へ何を起こすか。
- 消失記録が個人メモから、他者と事実を共有する証拠へなりうるか。
- Phaseを引き延ばすために新しい異常を大量追加せず、既出の異常が別の場所・社会で持つ意味を描く。

### Phase終了時に判明してよいこと

- 異常がハルカ村だけの局所現象ではない。
- 地域ごとに見え方は違っても、既出の消失・破損・fallback系列として接続できる。
- 公的な組織や記録も、異常の外側にはいられない。
- ユウとリゼが、個人の目撃者から継続的な観測者へ役割を変え始める。

### まだ明かしてはいけないこと

- 世界の外側にある記録の正体。
- Recovery Agentの全権限と起源。
- 魔王と容量不足の正確な因果。
- 二人のセドを、独立した時間移動／並行世界設定として確定する説明。
- 世界を救う最終手段。

### 次Phaseへの出口条件

- 異常が複数地域または公的記録にまたがる証拠を得る。
- 王都、教会上層、公的記録機関のいずれかへ向かう必然が生まれる。
- 消失記録が、個人的な忘備録以上の価値を持つと人物たちが認識する。

## Phase III：人間の記録と世界の記録

**範囲**：王都、教会、公的記録  
**状態**：完了（episode-20）。王都の公的記録を通して「記録が人をどう扱うか」を描き、北街道では消えた見張り台の直前に魔王軍旗が目撃された。魔王軍と異常の因果は未確定だが、無視できない相関と、行方不明者を追って北へ進む理由がそろった。
**参考話数**：episode-11〜20前後  

### 開始時に読者が知っていること

- 異常は地域を越え、人間社会の記録と認識を変える。
- 消失記録は、消えた事実を外に残す手段として機能している。
- 創世記には一時、「世界の外側に記録を置いた」という一節が現れた。

### このPhaseで意味を更新する既存設定

- 人間が作る記録と、世界が保持する記録の違い。
- ルミナ信仰、教会、公的記録が、消失に対して持つ本当の価値と限界。
- 「世界の外側」という言葉と消失記録の関係。

### Phase終了時に判明してよいこと

- 消失記録の価値が社会的・物語的に増す。
- 世界の外側に何らかの記録がある可能性が、複数の証拠で強まる。
- Recovery Agentという用語が、単なる表示以上の意味を持つと分かり始める。

### まだ明かしてはいけないこと

- 世界の外側の完全な構造。
- 最終選択の具体的内容。
- 魔王を倒せば解決しないという最終結論を、事件なしに先に説明すること。

### 次Phaseへの出口条件

- 魔王と異常の相関を無視できない証拠が揃う。
- 登場人物が魔王を「答え」として追う、十分な物語上の理由ができる。

## Phase IV：魔王という答え

**範囲**：魔王の活動圏と、その影響下  
**参考話数**：episode-21〜30前後  
**状態**：進行中（episode-21〜）。北の稜線では、三本の魔王軍旗と北向きの防御陣、北側から旗を貫いたロアの矢が確認され、捜索先は旗の向こう側へ移った。魔王本人・軍勢の実在範囲・陣を築いた者・見張り台消失との因果はまだ確認されていない。

### 開始時に読者が知っていること

- 魔王の活動と異常には強い相関がある。
- 社会は一貫して魔王を原因だと考えている。
- 世界の記録と容量には、別の問題がある可能性も示されている。

### このPhaseで意味を更新する既存設定

- 魔王は異常の原因に見えるが、世界容量を大きく消費する一存在でもある。
- 「敵を倒すこと」と「世界を直すこと」は同じではない。

### Phase終了時に判明してよいこと

- 魔王は根本原因ではない。
- 魔王を倒す／活動を止めることで一時的に改善しても、消失は止まりきらない。
- ユウの役割は敵の討伐ではなく、残すものを選ぶ方向へ移る。

### まだ明かしてはいけないこと

- 最終的に残す対象と失う対象。
- Recovery Agentの最終判断を誰が設計したか。
- 最終解決の具体的手順。

### 次Phaseへの出口条件

- 魔王を答えとする仮説が崩れる。
- 世界全体を元どおりにはできないと、ユウが避けられない事実として理解する。
- 消失記録が最終判断に関わる位置へ到達する。

## Phase V：何を残すか

**範囲**：世界の真因とRecovery Agentの役割  
**参考話数**：episode-31以降。全体35〜45話程度を中心値とし、30〜50話程度の範囲で収束させる目安  
**状態**：終盤

### 開始時に読者が知っていること

- 世界は全部を保持できない。
- 魔王を倒すだけでは消失が止まらない。
- ユウは「ないもの」を直せず、消失記録だけが存在した事実を残してきた。

### このPhaseで意味を更新する既存設定

- Recovery Agentは「全部を修理する者」ではなく、限られた条件の中で何を残すか判断する役割へつながる。
- 消失記録は忘備録から、世界で最も重要な書物へ意味が変わる。
- 「ないものは、直せない」は無力の宣告ではなく、選択の出発点になる。

### Phase終了時に判明してよいこと

- 世界の真因。
- Recovery Agentの物語上の意味。
- ユウが何を残し、何を失うかという選択。
- 消失記録の最後のページにユウ自身の名前を書く意味。

### 現時点で固定しないこと

- 誰を残すか。
- 何を失うか。
- 世界がどの形で存続するか。
- ユウ、リゼ、魔王の最終的な生死と関係。
- 最終章の事件、手順、台詞、章末。

### 物語の終着条件

- ユウが「全部直す」発想から「何を残すか選ぶ」人物へ到達する。
- 選択が作品のテーマ、消失記録、Recovery Agent、魔王、世界の外側の記録を一つの意味へ収束させる。
