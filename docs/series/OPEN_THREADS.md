# OPEN THREADS

> 未回収伏線と、即興で生まれたSSRを追跡する。
> `OPEN` は未回収、`PARTIAL` は一部だけ意味更新済み、`CLOSED` は本文で回収済み。

## 運用ルール

- 本文で新しい謎を採用したら、その話の確定作業と同時に登録する。
- 「作者側で確定」と「まだ未確定」を分ける。未確定欄を執筆AIが勝手に埋めない。
- 回収時は項目を削除せず、状態、回収episode、更新された意味を追記する。
- 既存伏線の別名にすぎない場合、新規IDを増やさず関連項目を更新する。
