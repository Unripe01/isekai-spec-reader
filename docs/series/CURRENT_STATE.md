## 次話で守る境界

- 現在のセドを「偽物」と即断しない。
- 二人のセドのどちらかを偽物、失敗作、優先される側と即断しない。
- 二人のセドを新しい独立法則にしない。既出のfallbackとの関係を、記録・証言・経過の差から観測する。
- 宿帳から北街道のセドの記録が消えたことを、「後から増えた方が必ず消える」法則にしない。
- 消失記録が残った理由を、外部記録だからと即断しない。宿帳も人が手で書いた記録である。
- 出来事と人物の対応の食い違いを、記憶の入れ替わり、世界が一人へ統合していること、北街道のセドの消去と即断しない。
- 宿場詰所の帳面の書き換わりを、ユウが功績を奪う／世界がユウを優先する／手書きの公的記録が必ずユウへ変わる法則と即断しない。
- 報告書二部の相違を、どちらかが偽物／一方だけが正史／複製記録は必ず現在の認識へ書き換わる法則と即断しない。
- 相違を見つけたことで、ユウが記録の正しさや世界の過去を確定できるようになったとは扱わない。現時点では、相違を保留して比較記録へ残す方法を得た段階である。
- 王都衛兵隊の併置保管を、二人のセドの身元・法的扱い・社会上の結論が永続的に不要になる解決策とは扱わない。
- 二人のセドが不在だったことだけから、episode-08の書き換わりを既存のセド問題と無関係な新法則にしない。
- 北街道のセドの記憶喪失と十五日のセドの新しい記憶が同時に起きても、「記憶が移動した」「片方から片方へ統合されている」と即断しない。
- ユウに「全部は残せない」「何を残すかを選ぶ」という最終回答をこの段階で悟らせない。現在は、限られた紙へ必要な観測を書き残す実務判断にとどめる。
- 世界の真相やRecovery Agentを説明しない。
- 新しい大怪異を重ねるより、今ある矛盾を人物・証拠・記録から掘る。
