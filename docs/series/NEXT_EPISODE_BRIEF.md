# NEXT EPISODE BRIEF

> 次話を書くための引き継ぎメモ。本文正史ではなく、執筆前に必ず読み直す。

## 現在の読後感

- episode-15〜16で、セド二人の「同じ名を既存帳票で表せない」問題は、別々の元記録を保つことでいったん画面外の観測へ移せた。二人を人間扱いするための記録は残すが、毎話の主筋にしない。
- episode-17は、北街道から来た黒牙狼の襲撃が油ランプの火災と崩落までの時間制限へつながる一事件になった。名簿にいないメルを、サラの言葉と上着という具体的な手がかりで先に人として置いた。
- ユウは「確定するまで保留」という強みを持ったまま、救助では「分からない。でも、まだいるなら間に合う」と行動を選んだ。メルは救出済みで、二人のセドは王都で観測継続中。

## 今後の執筆ルール

- 整合性・判断保留・意味更新は採用条件であり、物語の目的ではない。
- 各話に、誰かの具体的な望み、能動的な障害、失敗時の損失、選択、不可逆な変化を置く。
- 記録のテーマは、救う・追う・対立する・旅立つために必要になったときに使う。帳票の改善だけで閉じない。
- 大事件を重ねず、複数の危機があるなら原因→結果→期限の一事件にする。危機の人物を名無しの証拠役にしない。
- 戦闘は義務ではない。入れるなら、ユウが万能に倒すのではなく、他者の意志と行動が事件を動かす形にする。

## 次話の執筆意図

- episode-18は、北街道救援隊に加わったユウとリゼを主軸にする。目的は、王都外縁へ来た黒牙狼の経路をたどりつつ、街道側に残った人を救う／見つけること。
- セド編は終了ではなく王都での背景観測。記録所からの報告が必要になるまで、同じ帳票の検証を繰り返さない。
- メルの名簿欠落は即解決しない。ミナやセド、fallbackと同一原因だとも断定しない。サラとメルの救助後の関係は、事件の人間的な余韻として扱ってよい。
- 北街道の五本脚の狼、街道の被害、救援隊内の判断を使う。ただし「また名簿が消えた」だけの反復や、無関係な災害の上乗せは避ける。
- SYSTEM LOGは、既存ログの意味を本当に変える局面まで再表示しない。
