# STORY BIBLE

> 『異世界の仕様を読み解く者』の長期連載用「憲法」。
> 頻繁に変わる現在地や個別事件ではなく、作品を通して守る不変条件だけを管理する。

## この文書の扱い

- `[本文確定]`：episode本文で読者に提示済み。無言で変更しない。
- `[作者側固定]`：制作側では確定しているが、本文で説明済みとは限らない。
- `[未確定]`：今後の即興余地。本文や管理文書で勝手に確定させない。
- 新しい事件・地名・人物・伏線は、原則として `CANON_LEDGER.md` または `OPEN_THREADS.md` へ記録する。この文書へ追加するのは、作品全体を拘束する不変ルールになった場合だけ。

## 作品の核

### 基本コンセプト

[作者側固定]

一見すると、魔王復活の兆候に立ち向かう王道ダークファンタジー。しかし実際には、世界から物、記録、記憶、人が消え、古い／別の状態まで不完全に成立し始めている。

物語の中心は「仕様を読んで無双すること」ではない。

**消えていく世界で、何を残すのかを選ぶ物語。**

### 作品テーマ

- 記録とは何か。
- 記憶から失われた存在は、存在したと言えるのか。
- 世界を救うためなら、何かを消してよいのか。
- 誰が「残す価値」を決めるのか。
- 全部を直せないとき、何を残すのか。

### 重要な言葉

> 消えたものは、忘れる。
>
> 自分も例外ではない。
>
> ないものは、直せない。
>
> 存在したことだけは、守れるかもしれない。
>
> 世界が終わるとき、誰がそれを覚えているのだろう。

## 世界の基本ルール

### 表側の世界

[本文確定]

- 作中人物にとって魔法は魔法、祝福は祝福、神は神、魔王は魔王である。
- 十二歳になると教会で祝福の鑑定を受ける。
- 一般社会は増加する異常を「魔王復活の兆候」と解釈している。
- 記録と知恵の女神ルミナが信仰されている。
- 王都はアルセリア。ハルカ村、リーベルなどの土地が存在する。

### 世界の裏側

[作者側固定]

- 世界は巨大なシステムに似た構造を持つ。
- 人、魔物、建物、魔法、歴史、死者、記憶、記録などが長い年月にわたり蓄積され、保存可能領域が限界に近づいている。
- 世界は適切に整理されないまま運用されてきた。容量不足と破損が、消失や異常動作の根にある。
- この説明を序盤のナレーションや登場人物の断定として書かない。「世界はコンピュータ／サーバー」と確定説明しない。

### 消失の段階

[本文確定／作者側固定]

消失は、必ずしも全対象で同じ速度・同じ順序ではないが、次の方向へ進行する。

1. 物理的な存在が消える。
2. 公的記録、地図、文書、歌などが自然に改変・欠落する。
3. 人の記憶から形や内容が薄れる。
4. 存在したという認識そのものが失われる。
5. 人間も、部屋・記録・周囲の記憶ごと「最初から存在しなかった」状態になる。

対象は物、建物、道、言葉、歌、記録、人間まで広がる。消えたものは、参照元が存在しない限り戻せない。

### fallback系異常

[本文確定／作者側固定]

- episode-02で `REGION LOAD FAILED`、`Attempting fallback...`、`Fallback source integrity: 62%` が提示された。
- episode-03では、夜だけ増える道、五日を数時間として経験したセド、同時に存在する可能性のある二人のセドが発生し、`Fallback instance detected` と `Active entities: 2` が表示された。
- これは「時間移動」「並行世界」「分身魔法」という独立した新法則ではない。既出の `fallback` が不完全な代替状態を成立させうる、と意味が更新されたものとして扱う。
- fallbackの完全な機構、選択元、二つのセドの解決方法は未確定。面白さだけを理由に別の宇宙論を追加しない。

## 魔王

[作者側固定]

- 魔王の活動と異常発生には強い相関がある。
- 魔王は人類から見れば最大の脅威であり、一度は異常の根本原因に見えてよい。
- ただし魔王は根本原因ではない。世界の容量を大きく消費する存在の一つである。
- 魔王を倒すことで一時的に状況が改善しても、世界の消失そのものは止まらない。
- 「敵を倒せば全部解決する物語」にはしない。

## ユウ

### 不変のコア

[本文確定]

- 二十七歳。元の世界ではSE系の仕事をしていた。
- 合理的で、面倒事と無駄を嫌う。
- 仮説と事実を分け、再現条件と変化点を探す。
- 分からないものを分かったことにしない。
- ヒーローを志望せず、正義感を振りかざさないが、困っている人を放っておけない。
- 自分の都合だけで無関係な人を犠牲にしない。
- 危険な状況ほど比較的冷静。軽い冗談や現代人的なツッコミは残る。

### 能力でできること

[本文確定]

- 異常な対象、とくに触れた対象の「おかしい箇所」を感覚的に知覚する。
- 本来存在しないもの、重複、絡まり、破損、参照不能、missing dataなどを認識する場合がある。
- 余計な部分を外す、絡まりをほどく、残っている断片をつなぐことで、異常を修正できる場合がある。
- 通常は読めない異質な表示の意味を、ユウだけが認識する場合がある。

### 能力でできないこと

[本文確定／作者側固定]

- 世界の正常な仕様を自由に一覧表示できない。
- 相手の能力や状態を常時鑑定できない。
- 異常の原因、世界の真相、正しい修復手順が自動的に分かるわけではない。
- 参照元や欠損データがないものは復元できない。
- 消えた人や物を無から作り直せない。
- 何でも触れば安全に直せるわけではない。
- 一般攻撃や任意削除の万能スキルとして扱わない。

**「ないものは、直せない」制約を破らない。**

### 成長の方向

[作者側固定]

開始時は「問題には原因と直し方がある」と考える。最終的には、全部を直せないことを知り、正解を探すだけではなく、何を残すかを選ぶ人物へ変化する。

### 転移／転生の扱い

[本文確定／未確定]

- 本文では、元の世界の記憶を持つユウがパーカーとジーンズ姿で森に突然現れた。
- 現状の描写は「異世界転移」寄り。
- 死因、転生方式、転移させた主体、選定理由は未確定。必要になるまで新しく断定しない。

## Recovery Agent

[作者側固定]

- 世界の裏側では、ユウは `Recovery Agent` として扱われている。
- 鑑定時には通常の祝福が表示されず、ユウにだけ一瞬 `AGENT` と見えた。
- `Cleanup permissions: LIMITED` のため、ユウに無制限の権限はない。
- Recovery Agentの由来、誰が定義したか、ユウが選ばれた理由、最終的な役割の全容は未確定。
- ユウ本人・リゼ・一般社会・序盤の読者に正体を説明しない。公式サイトでも伏線としてのみ扱う。

## リゼ

### 不変のコア

[本文確定]

- 巡礼神官。銀髪、紫色の瞳。《白光》の祝福を持つ。
- 冷静で生真面目。観察力があり、少し頑固。
- 証拠と事実を重視し、分からないことを分かったふりしない。
- 信仰心はあるが盲信しない。
- 結論を出せないことは「保留します」と言える。
- 不安や恐怖が強いほど、言葉遣いが丁寧になる。
- ユウを簡単には信じないが、記憶と記録が矛盾したとき、手書き記録を証拠として採用できる。

### ユウとの関係

[作者側固定]

- 序盤は世界の異常を調査する相棒。信頼が先で、恋愛は後から自然に育てる。
- リゼを世界設定の説明係にしない。信仰、判断、葛藤、目的を持つ人物として動かす。

## 消失記録

[本文確定／作者側固定]

- episode-02でユウが作り始めた手書きの外部記録。
- 世界から消えたものを、忘れないために残す。
- `manual record detected`、`externalized memory may resist cleanup` と表示され、世界内部の記録より消失に抵抗する可能性がある。
- 記録を読むことで、失われた記憶そのものではなく、存在した事実を再構成できる。
- 改ざん不能・絶対安全とはまだ確定していない。万能なバックアップにしない。
- 物語終盤には世界で最も重要な書物となり、最後のページにユウ自身の名前を書く展開へつなげる。

## SYSTEM LOG

### 役割

- 読者への説明ではなく、ファンタジー本文へ混入する異質な伏線。
- 章末や本当に必要な転換点で、ごく短く出す。
- 読者が忘れかけた頃に出る程度とし、通常の地の文まで機械的にしない。
- 作中人物に「これはサーバーログだ」と説明させない。
- 既出ログの意味を更新することを優先し、同義の新用語を増殖させない。

### 既出系列

- Capacity／容量不足：`Available Capacity`、`Insufficient space.`
- Recovery：`AGENT`、`Recovery Agent status: ACTIVE`、`Cleanup permissions: LIMITED`
- 消失：`object not found`、`Entity deletion detected`
- 記録：`manual record detected`、`externalized memory may resist cleanup`、`Manual archive: CREATED`
- 地域復旧：`REGION LOAD FAILED`、`Attempting fallback...`、`Fallback source integrity: 62%`
- 重複：`Fallback instance detected`、`Entity consistency check: FAILED`、`Active entities: 2`、`Resolution: PENDING`

## 文体・演出の不変ルール

### 基準

- episode-01／02の空気感、異常の見せ方、会話の温度感を基準にする。
- 一文ごとの細かい改行と短文の連続は踏襲しない。地の文は通常の小説として読める、意味のつながる二〜五文程度の段落を基本とする。

### 重要場面ほど刻まない

- 重要場面だからという理由で文章を刻まない。一つの思考、因果、状況説明は原則として同じ段落で完結させる。
- 短文を独立させるなら、その場面で本当に一番強調したい一文だけを選ぶ。一つの場面で連続使用しない。
- 異常の怖さは文章の形ではなく、**普通に読める文章の中に、成立してはいけない事実が存在すること**によって作る。

### 怪異の見せ方

- 普通に読める文章の中へ「成立してはいけない事実」を一つ置く。
- 恐怖を形容詞で説明しすぎない。ありえない出来事ほど淡々と書く。
- 新設定を増やすより、既知の事実の意味を後から更新する。
- 異常は「少し変だ → 説明できない → 成立しない → 前提が崩れる」の順で段階を作る。
- 簡単な言葉を、少しだけ嫌な位置に置く。難解な比喩や意味深な体言止めを連発しない。

### 会話と人物

- ユウとリゼの軽いツッコミ、ずれた返答、真顔の応答を残す。
- ユウのSEらしさはIT用語ではなく、切り分け、記録、事実確認、保留という思考に出す。
- リゼを説明係にしない。
- 通常の移動、食事、会話は普通に読みやすく書く。すべてを名文にしようとしない。

## 絶対にやらないこと

- IT知識だけで世界を見抜き、無双させる。
- ユウに正常なものを含む万能鑑定を与える。
- 欠損したものを制約なく復元する。
- 世界の真相を序盤の説明台詞やナレーションで明かす。
- 面白そうという理由だけで、既存伏線と無関係な世界法則を追加する。
- fallbackを安易に時間旅行、並行世界、分身魔法へ分離する。
- SYSTEM LOGを頻発させたり、登場人物が機械用語で説明したりする。
- キャラクターの不変コアを、展開の都合で変える。
- リゼを説明係にする。
- ユウとリゼを十分な信頼の蓄積なしに恋愛関係へ進める。
- 未来の具体的な事件、犯人、章末、最終選択を必要以上に先決めする。
